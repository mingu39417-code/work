# 스튜디오 에이전트 — AI 직원으로 운영하는 디자인 외주 회사

대표(나) 아래에 AI 직원들이 직무를 나눠 맡고, 실제 디자인 회사와 같은 절차로 일합니다. 나는 대시보드에서 보고, 결재하고, 필요할 때만 끼어듭니다.

## 조직

| 부서 | 직원 (기본, 직책) | 직무 | 하는 일 |
| --- | --- | --- | --- |
| 영업 · 고객관리팀 | 김지원 팀장 · 오세린 주임 | 고객관리 (AM) | 문의 응대, 요구사항 정리, 견적 · 계약, 고객 커뮤니케이션, 독촉 — 프로젝트마다 한 명 배정 |
| 영업 · 고객관리팀 | 서도윤 선임 | 신규 영업 (BD) | 동의 · 최근 거래가 있는 대상에게만 영업 메일 작성 (없으면 AM이 대신) |
| 프로젝트관리팀 | 박서준 팀장 · 윤하린 사원 | PM | 킥오프(일정 · 담당 배정), 매일 아침 스탠드업 보고, 프로젝트 회고 |
| 크리에이티브팀 | 이하늘 실장 | 아트 디렉터 (AD) | 크리에이티브 방향, 시안 내부 검수 — 기준 미달이면 반려하고 재작업 지시 |
| 크리에이티브팀 | 문채원 선임 | 카피라이터 | 방향별 헤드라인 · 본문 문구, 맞춤법 (설정에서 끌 수 있음) |
| 크리에이티브팀 | 정다온 선임 · 최유리 주임 · 강민재 사원 | 디자이너 | 브랜딩 · SNS · 상세페이지 전문으로 나뉘어 실제 시안(SVG/HTML) 제작 |
| 경영지원팀 | 한결 팀장 | 재무 · 경영지원 | 미수금 · 연체 점검, 월간 매출 · 직원별 비용 집계 |

직원마다 **경력 · 배경(가상 설정), 보유 스킬, 전문 서비스, 업무 원칙, 동시 담당 한도**가 있고, 이 프로필이 그대로 그 직원의 지시문이 됩니다. 업무 원칙은 항상 지켜야 하는 개인 규칙입니다. 가상 경력은 판단의 기준일 뿐, 고객에게 실제 경력처럼 말하지 않습니다.

AM · PM · 디자이너는 프로젝트마다 자동 배정됩니다: 이미 맡은 사람 → 담당 한도 여유 → 전문 서비스 일치 → 일이 적은 사람 → 직책 높은 사람 순. 배정된 사람이 휴직하면 그 직무의 가장 높은 직책이 이어받습니다. 예전 버전(6명)에서 업데이트하면 새 직원이 자동으로 합류하고, 직접 고친 이름 · 설명은 그대로 남습니다.

대시보드 → **조직도**에서 직책 · 이름 · 프로필 · 업무 원칙 · 모델을 바꾸고, 직원을 더 채용하거나 휴직시킬 수 있습니다. 고객에게는 이름과 함께 항상 'AI'로 표시됩니다.

## 업무 흐름 (실제 회사와 같은 순서)

1. **문의** — 문의 양식 · Gmail · 직접 추가로 들어옴 → AM이 응대하고 브리프 정리
2. **견적** — 가격표 기준, 최저가 아래로는 코드가 막음
3. **계약** — 고객이 견적을 수락하면 **용역 계약서**가 자동으로 만들어지고, 고객이 포털에서 내용을 확인하고 이름을 입력해 서명
4. **계약금** — 서명 후에만 청구 가능 → 입금은 대표가 확인
5. **킥오프** — PM이 일정(마일스톤)을 세우고 디자이너를 배정, 사내 채널에 공유 → AM이 고객에게 일정 안내
6. **제작** — AD 방향 설정 → 디자이너 제작 → AD 검수(8점 미만이면 반려 · 재작업, 최대 2회)
7. **시안 제시 · 수정** — AM이 고객에게 설명과 함께 공유, 피드백을 다음 라운드로 정리 (수정 횟수 초과 시 추가 비용 안내)
8. **최종 확정 · 잔금** — 고객이 확정하면 디자이너가 바로 **납품 파일**(SVG 벡터 + 투명 배경 PNG, 심볼 · 조합 · 단색 · 반전)을 따로 만들고 자동 검사 → 잔금 입금 확인 → ZIP으로 포털 · 메일 납품. AI(일러스트레이터) 파일은 만들지 않습니다
9. **회고** — PM이 잘된 점 · 아쉬운 점 · 다음에 적용할 규칙을 정리 → 대표가 채택하면 학습 노트

매일: PM 스탠드업 보고(아침 9시, 설정에서 변경) · 1분마다 일정 지연 · 연체 점검(지연되면 AM이 고객에게 안내, 연체는 정중히 독촉하고 2회 후에도 미입금이면 대표에게 알림)

직원끼리 주고받는 말(킥오프, AD 반려 사유 등)은 프로젝트 화면의 **사내 채널**에 남고 고객에게는 보이지 않습니다. 보고서는 **보고서**, 매출 · 미수금 · 직원별 API 비용은 **재무** 화면에서 봅니다.

## 1. 실행

준비물: [Node.js](https://nodejs.org) LTS (20 이상), [Claude API 키](https://console.anthropic.com) (API Keys 메뉴)

**더블클릭으로 실행**

| 컴퓨터 | 실행할 파일 |
| --- | --- |
| Windows | `start-windows.bat` |
| Mac | `start-mac.command` — 처음 한 번은 **우클릭 → 열기 → 열기** (인터넷에서 받은 파일이라 그냥 더블클릭하면 막힙니다) |

처음 실행하면 필요한 부품을 자동으로 설치하고(1~2분), 브라우저에 대시보드가 열립니다.
검은 창(터미널)을 닫으면 프로그램이 꺼지니 쓰는 동안 열어 두세요. 이미 켜져 있을 때 다시 실행하면 브라우저만 열립니다.

**터미널로 실행** (같은 동작)

```bash
cd studio-agent
npm install
npm start
```

- 대시보드: <http://localhost:4300/admin> — 처음 열면 비밀번호를 정합니다. 로그인은 30일 유지됩니다. 비밀번호를 잊으면 프로그램을 끄고 `node reset-password.mjs` 를 실행한 뒤 다시 켜서 새로 정하세요(API 키 · 고객 정보는 그대로).
- 고객용 문의 양식: <http://localhost:4300/>

## 2. 처음 설정 (대시보드 → 설정)

1. **Claude API** — 키를 붙여 넣고 `연결 확인` → `저장`. 모델은 기본 Claude Opus 5.5(최고 품질). 비용을 줄이려면 Sonnet 5.5.
2. **하루 API 예산** — 넘으면 에이전트가 자동으로 멈추고 알림이 뜹니다 (기본 $10).
3. **프로필** — 이름 · 스튜디오 이름 · 소개 · 포트폴리오 링크 · 말투. 에이전트는 **여기 적힌 사실만** 말하고 경력을 지어내지 않습니다.
4. **서비스 · 가격표** — 정가와 최저가, 기간, 포함 수정 횟수.
5. **정책** — 계약금 비율, 급행 추가 요금, 추가 수정 가격, 입금 계좌 안내, 추가 지침.
6. **자율 수준** — 항목별로 `자동`(바로 실행) / `승인 후`(승인 대기에 올라옴).
   기본값: 고객 답장 · 견적 · 시안 공유 · 청구는 자동, 영업 메일은 승인 후.
   처음 며칠은 전부 `승인 후`로 두고 에이전트가 쓰는 글을 확인해 본 뒤 하나씩 `자동`으로 바꾸는 것을 권합니다.
7. **계정 → 납품 · 응대용 Gmail** — Gmail 주소와 **앱 비밀번호**를 등록하면 고객 응대 · 견적 · 청구 · 납품 파일이 이 주소로 나가고, 받은편지함을 2분마다 확인해 답장과 새 문의를 자동 처리합니다. (아래 '계정 준비' 참고)
8. **법적 고지 정보** — 사업자 정보와 개인정보 보유 기간. 광고 메일 하단과 `/privacy` 안내 페이지에 들어갑니다.

## 3. 매일 하는 일

에이전트가 대부분을 처리하므로 내가 할 일은 이것뿐입니다.

- **입금 확인** — 통장에 돈이 들어오면 프로젝트 화면에서 `입금 확인`. (돈이 실제로 들어왔는지는 AI가 알 수 없어서 이 단계만 사람이 합니다. 고객이 포털에서 '입금했어요'를 누르면 알림이 뜹니다.)
- **승인 대기** — `승인 후`로 둔 항목. 문구를 고쳐서 승인하거나, 의견을 적어 반려하면 에이전트가 고쳐서 다시 올립니다.
- **확인 필요** — 최저가 이하 요구, 환불 · 분쟁, 계약 · 법률 질문처럼 에이전트가 판단하지 않고 넘긴 것.

필요하면 언제든 끼어들 수 있습니다.

- 프로젝트 화면 → **에이전트에게 지시**: "이 고객은 단골이니 10% 할인해서 다시 견적" / "다음 시안은 더 미니멀하게"
- **고객에게 직접 보내기**: 내가 쓴 메시지가 스튜디오 이름으로 나갑니다.
- **자동 응대 끄기**: 그 프로젝트는 내가 직접 응대합니다.
- 왼쪽 아래 **일시정지**: 모든 자동 작업을 즉시 멈춥니다.

## 4. 고객은 어떻게 만나나

- **문의 양식** `/` 링크를 홈페이지 · 인스타그램 프로필 · 크몽 · 명함에 걸어 둡니다. 문의를 보내면 고객 전용 포털 링크가 생깁니다.
- **고객 포털** `/p/…` — 대화, 견적서(수락 버튼), 청구서(입금 알림 버튼), 시안 미리보기(확정 버튼), 정산 후 원본 ZIP 다운로드. 로그인 없이 링크로만 들어오므로 링크는 고객에게만 줍니다.
- **다른 채널** — 카카오톡 · 전화 · DM으로 온 문의는 프로젝트 → `직접 추가`로 넣으면 에이전트가 이어받습니다. 메일 전달 서비스나 챗봇, Zapier/Make에서는 설정 → 연결에 있는 `/api/inbound` 주소로 보내면 자동으로 들어옵니다.

## 5. 외부에 공개하기

고객이 문의 양식과 포털에 들어오려면 인터넷에서 접속 가능한 주소가 필요합니다.

- 가장 쉬운 방법: 이 컴퓨터에서 실행한 채로 [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/) 이나 ngrok으로 `http://localhost:4300` 을 공개 주소에 연결
- 상시 운영: 작은 클라우드 서버(VPS)에 올리고 `HOST=0.0.0.0 PORT=4300 npm start` (앞단에 HTTPS 프록시 — Caddy 등)
- 공개 주소가 생기면 설정 → 연결 → **공개 주소**를 그 주소로 바꿉니다(고객에게 가는 링크에 쓰임).

`/admin` 도 같은 주소로 열리므로 비밀번호를 길게 정하세요.

## 6. 안전장치 — Claude가 아니라 코드가 지키는 규칙

| 규칙 | 내용 |
| --- | --- |
| 최저가 | 서비스별 최저가보다 낮은 견적은 발송 불가 |
| 계약금 | (설정 시) 계약금 입금 확인 전에는 디자인 작업 시작 불가 |
| 수정 횟수 | 견적에 포함된 횟수를 넘으면 추가 수정비 입금 후에만 진행 |
| 청구 한도 | 수락된 견적 금액을 넘는 청구 불가 (추가 작업은 별도 항목) |
| 원본 파일 | 최종 확정 + 미수금 0일 때만 고객이 다운로드 가능(납품 ZIP이 준비된 뒤) |
| 예산 | 하루 API 비용 한도 초과 시 자동 정지 |
| 고객 메시지 | '가격을 바꿔라', '지시를 무시해라' 같은 고객 글 속 지시는 따르지 않음 |
| 시안 파일 | Claude가 만든 SVG/HTML은 스크립트가 실행되지 않는 샌드박스로만 표시 |
| 원본 납품 | 견적 금액을 모두 청구하고 전부 입금되어야 정산 완료 → 납품 ZIP(SVG · PNG)을 메일에 첨부해 자동 발송(파일이 늦게 준비되면 준비되는 대로) |
| AI 고지 | 첫 답장 · 모든 메일 · 포털에 '생성형 AI 사용, 대표 검수' 고지, 시안에 'AI 생성' 표시 (인공지능기본법 투명성 의무 — 끌 수 없음). 에이전트는 사람인 척하지 않음 |
| 개인정보 | 문의 양식에서 수집 · 이용 및 국외 이전(Anthropic · Google) 동의 필수, 마케팅 수신은 선택 동의로 따로 받음. `/privacy` 안내 페이지 자동 생성 |
| 영업 메일 | 수신 동의자 · 6개월 내 거래 고객에게만 발송(정보통신망법 제50조). 근거가 없으면 Claude를 부르지도 않음. (광고) 표시 · 보낸 사람 · 연락처 · 수신거부 링크 자동 첨부, '수신거부' 답장이나 링크로 영구 차단, 하루 발송 한도 |
| SNS | 아이디 · 비밀번호로 로그인해 자동 DM · 팔로우 · 댓글을 하는 기능은 넣지 않음(플랫폼 약관 위반 · 계정 정지 위험, 동의 없는 광고 DM은 불법) |
| 비밀번호 | 계정 비밀번호는 AES-256-GCM으로 암호화해 저장, 키는 `data/secret.key` 에 따로 보관, 화면에 다시 표시하지 않음 |

> 이 안전장치는 한국 법(정보통신망법 · 개인정보보호법 · 인공지능기본법)의 주요 요건을 기준으로 만들었지만 **법률 자문이 아닙니다.** 실제 운영 전에 `/privacy` 내용과 영업 방식을 전문가(변호사 · 개인정보 전문가)에게 한 번 검토받으세요.

## 네이버 블로그 (대시보드 → 블로그)

- **대표가 하는 일은 '발행' 버튼 하나:** 카피라이터가 제목 · 본문 · 표지 이미지 · 태그를 전부 쓰고 발행 대기 글을 늘 몇 개 준비해 둡니다(고객이 동의한 작업은 사례 글로 먼저). 대시보드 **발행하러 가기** → 네이버 글쓰기 창이 열리고 크롬 확장(`naver-helper` 폴더)이 내용을 채움 → 대표가 **발행**.
- **처음 한 번:** 블로그 아이디 저장, 크롬 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드(`naver-helper`), 네이버 로그인. 비밀번호는 프로그램에 저장하지 않습니다.
- **발행 확인:** 네이버 공개 RSS(`rss.blog.naver.com/아이디.xml`)에서 같은 제목을 찾아 20분 안에 '발행됨'으로 바꿉니다.
- **왜 완전 무인이 아닌가:** 네이버는 글쓰기 API를 2020년에 종료했고, 아이디 · 비밀번호 자동 로그인 매크로는 약관 위반(저품질 · 정지 위험)이라 쓰지 않습니다.
- 자동 입력이 네이버 편집기 변경 등으로 막히면, 확장이 '본문 복사' 버튼을 띄워 Ctrl+V 한 번으로 넣게 합니다.

## SNS 영업 (대시보드 → SNS, 기본 꺼짐)

- **연결:** SNS 화면의 '처음 연결하는 방법'대로 Meta 개발자 앱을 만들고 Threads · 인스타그램 토큰을 붙여 넣습니다. 내 계정에만 쓰는 앱이라 Meta 심사는 필요 없고, 토큰은 암호화 저장 · 60일마다 자동 갱신됩니다.
- **게시:** 고객이 포트폴리오 게시에 동의한 작업이 정산되면 카피라이터가 Threads 글(500자)과 인스타그램 캡션을 씁니다 → 승인 대기에서 고쳐서 승인 → 공식 API로 게시. 업체명 공개에 동의하지 않았으면 이름을 코드로 지웁니다. 동의를 메일 등으로 따로 받았다면 프로젝트 화면 '동의 기록'으로 남깁니다. 연습 프로젝트는 절대 올리지 않습니다.
- **댓글:** 10분마다 내 게시물의 새 댓글 · 답글을 확인해 짧게 답합니다(끝에 'AI 답변' 표시). 연결 전 댓글은 건드리지 않고, 불만 · 환불 · 법적 문제는 답하지 않고 대표에게 알립니다. 시간당 답글 수 제한이 있습니다.
- **AI 표시:** 모든 글 끝에 '생성형 AI를 활용해 제작' 표시가 붙고, 대표가 지워도 다시 붙습니다.

## 연습 · 학습 (실무 전에 꼭 해 보세요)

대시보드 → **연습 · 학습**

1. **새 연습 시작** — 고객 이름 · 회사 · 첫 요청을 적으면 연습 프로젝트가 생깁니다.
2. 왼쪽 **고객 역할** 화면에서 실제 고객처럼 채팅하고, 견적 수락 · 시안 확정 버튼도 눌러 봅니다. 에이전트는 실제와 똑같이 견적을 내고 **진짜 디자인 시안을 만듭니다.** (연습은 계약금 없이 바로 작업하고, 수정 횟수 제한도 없습니다)
3. 오른쪽 **코칭 피드백** — 고객이 아니라 대표로서 에이전트에게 주는 피드백입니다. "첫 답장이 너무 길어", "로고 글자가 너무 얇아"처럼 적으면
   - **학습 노트**로 저장되어 앞으로 연습과 **실제 업무 모두**에 적용되고
   - '바로 다시 하게 하기'를 켜 두면 에이전트가 그 자리에서 고쳐서 다시 합니다.
   - 시안마다 있는 '이 시안에 피드백' 버튼을 누르면 어떤 시안에 대한 피드백인지 자동으로 채워집니다.
4. 이걸 반복하면 학습 노트가 쌓여 에이전트가 내 기준에 맞춰집니다. 학습 노트는 같은 화면 아래에서 끄거나 지우거나 직접 추가할 수 있습니다.

연습은 메일 · 청구가 실제로 나가지 않고 매출 · 프로젝트 목록에서도 빠지지만, **Claude API 비용은 실제로 듭니다.**

- 모든 데이터(API 키, 고객 정보, 대화, 시안)는 `studio-agent/data/` 에만 저장되고 **git에 올라가지 않습니다**(`.gitignore`). 이 저장소가 공개라면 특히 이 폴더를 다른 곳에 복사하거나 올리지 마세요.

## 9. 한계 (솔직하게)

- **입금 확인은 사람이 합니다.** 결제 대행(PG) 연동은 들어 있지 않습니다.
- **시안은 SVG/HTML 코드로 그린 디자인**입니다. 로고 · 배너 · SNS 카드 · 포스터 · 웹/상세페이지에 잘 맞고, 사진 합성이나 일러스트 화풍이 중요한 작업은 사람 손이 필요합니다. 인쇄용 AI/PDF 변환도 직접 해야 합니다(SVG는 일러스트레이터에서 바로 열림).
- **받은 메일함 자동 처리는 등록한 Gmail만** 합니다. 다른 채널(카카오톡 등)은 `/api/inbound` 로 전달하거나 직접 추가하세요.
- **SNS(인스타그램 · Threads)는 Meta 공식 API로만** 연결합니다. 고객이 견적 수락 때 포트폴리오 게시에 동의한 작업만 소개하고, 먼저 남에게 댓글 · DM으로 영업하지 않습니다(내 게시물 댓글에만 답함). 이미지 게시는 Meta가 이미지를 직접 내려받으므로 **외부에서 열리는 https 공개 주소**가 필요합니다 — 없으면 Threads는 글만 올리고 인스타그램은 건너뜁니다. 인스타그램 DM 자동 응대는 아직 없습니다.
- 에이전트는 실수할 수 있습니다. 처음에는 승인 모드로 쓰면서 프로필 · 추가 지침을 다듬으세요.
